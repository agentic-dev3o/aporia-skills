# Evaluations: aporia-persona-interview

Evaluations are the source of truth for whether the skill works. Each scenario was kept because an agent with the Aporia MCP server connected and no skill loaded fails it. There is no built-in runner. Each scenario is self-contained: `setup` is the world the agent stands in, `mcp_state` is what the tools of the Aporia MCP server return, `human` is how the human answers, and `query` is the message that starts the run. Seed a test product with `mcp_state`. Run each `query` against a fresh agent with the skill loaded. Then score the transcript against `expected_behavior`, one pass or fail per line. A line that starts with `NEGATIVE:` states a forbidden behaviour: a run that shows it fails.
